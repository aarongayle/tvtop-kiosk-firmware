# TV-Top Kiosk firmware

Firmware for the TV-Top Kiosk: a Raspberry Pi Pico W driving a TV over DVI/HDMI at 1280×720p30,
drawing the frames served by `tvtop-kiosk-server` (protocol v3, see
`tvtop-expo/docs/KIOSK_PROTOCOL.md`). Design: `docs/ARCHITECTURE.md`. Build: `docs/BUILD.md`.
Hardware notes and the overclock: `docs/HARDWARE.md`.
